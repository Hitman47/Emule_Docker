🔄 Reconnexion automatique (anti-stall)

      

        Si aucun téléchargement ne progresse pendant le délai configuré, le système change automatiquement de serveur ED2K et relance la recherche de sources Kad.

🔖 Bookmarklet navigateur

      

        Glisse ce bouton dans ta barre de favoris. Sur une page avec des liens ed2k, clique dessus : le dashboard s'ouvre dans un nouvel onglet et ajoute les liens (fonctionne aussi depuis les sites HTTPS).
      

      

        📥 aMule Ajouter
        
      

      

        Autres façons d'ajouter : coller (Ctrl+V) des liens n'importe où sur le dashboard, glisser-déposer un lien depuis un autre onglet,
        ou ouvrir http://<ip>:8078/#add=ed2k://... (utilisé par le gestionnaire de protocole Windows, voir README).
